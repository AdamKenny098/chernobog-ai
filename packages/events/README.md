# @chernobog/events

Authoritative runtime Event Spine boundary established by OH-1B.

`packages/events/src` owns the runtime Event Spine implementation. The original `lib/chernobog/events` source is retained unchanged as a temporary compatibility/source-verification mirror because the accepted Phase 11F verifier inspects that historical location directly.

Production/runtime consumers are migrated to `@chernobog/events`. Historical verifier source is not rewritten by OH-1B v3.
