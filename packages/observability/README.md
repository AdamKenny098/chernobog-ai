# @chernobog/observability

OH-1M establishes the shared architecture-level observability vocabulary. It does not replace accepted Phase 11 diagnostics, Event Spine telemetry, or the Trust Trace.

Public concerns: trace IDs, structured diagnostic metadata, health metadata, execution trace shapes, timing metadata, and error metadata.

Full telemetry redesign remains OH-9. Composition/injection remains OH-1N.
