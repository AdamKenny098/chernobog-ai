# Milestone 6 Validation Checklist

## Build

- [ ] `npm run build` passes.
- [ ] Dev server starts without module resolution errors.

## Build Department

- [ ] `build department status` works.
- [ ] `build department plan create factory yard with train platform` writes a plan.
- [ ] `build department generate create factory yard with train platform` creates a pack.
- [ ] `build department full pipeline create factory yard with train platform` creates pack + review + preview.

## Pack Review

- [ ] `build department review latest` returns score and flags.
- [ ] `build department repair latest` refreshes metadata.

## Preview

- [ ] `build department preview latest` creates `.preview.schem` files.
- [ ] At least one `.preview.schem` opens in Schemat.io.

## Finalization

- [ ] `milestone 6 status` works.
- [ ] `write milestone 6 docs` writes docs.
