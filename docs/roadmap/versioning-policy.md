# Chernobog Versioning Policy

## Purpose

This file prevents roadmap confusion as Chernobog moves from the released V5.6 vault-brain foundation toward Chernobog Inc.

---

## Locked Decision

```txt
V5.6 has already been released.
```

Therefore, future work must not reuse V5.6 as if it is an unreleased milestone.

---

## Versioning Rule

Use patch-style continuation for hardening work after an already released milestone.

Correct:

```txt
V5.6.1
V5.6.2
V5.6.3
```

Incorrect:

```txt
V5.6A
V5.6B
V5.6C
```

unless those labels were used before release and are only being discussed historically.

## Chernobog Inc Rule

Chernobog Inc begins properly at V6.0.x.

Earlier work can prepare for it, but should not claim the Inc layer exists until the following are implemented:

```txt
- mission state
- agent registry
- department reports
- executive report merger
- project lead layer
- permissioned tool gateway
- persistent mission UI
```
