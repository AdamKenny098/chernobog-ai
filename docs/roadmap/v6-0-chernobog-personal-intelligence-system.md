# V6.0 — Chernobog Personal Intelligence System

## Purpose

V6.0 unifies the V5.6 through V5.9.6 foundation into one CEO-directed operating loop.

V6.0 is not a random feature drop. It is the point where the following systems start behaving as one coherent assistant platform:

- structured vault memory
- approved memory recall
- vault-only answering
- project/version state
- current-state briefing
- trust/governance
- Chernobog Inc departments
- mission records
- controlled execution planning
- V6 readiness checks

## Core Operating Loop

```txt
CEO direction
  -> Executive Core interpretation
  -> approved vault context
  -> governance review
  -> department routing
  -> mission proposal
  -> controlled execution plan
  -> approval checkpoints
  -> reporting
  -> candidate memory update proposal
```

## What V6.0 Adds

- V6 Personal Intelligence System status
- V6 CEO operating loop
- V6 operating packets
- governance-aware department routing
- mission proposal recommendations
- explicit execution boundaries
- candidate memory update proposal boundary
- API route for Personal Intelligence packets

## What V6.0 Does Not Add

- free-roaming autonomous agents
- ungated tool execution
- automatic file writes
- automatic mission execution
- automatic memory approval
- bypassing governance

## Completion Condition

V6.0 is complete when Chernobog can take CEO direction and produce a governed operating packet that shows:

- project scope
- inferred work type
- governance decision
- recommended departments
- recommended mission title/objective
- operating-loop phase status
- approval requirements
- execution boundary
- memory update proposal boundary

The packet must not execute tools.
