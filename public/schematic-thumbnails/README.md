# Schematic Thumbnails

Place optional schematic thumbnail images in this folder.

Recommended naming:

```txt
<schematic-id>.png
```

Supported extensions:

```txt
.png
.webp
.jpg
.jpeg
```

The UI also checks slugified filenames when the raw schematic id contains characters that are awkward for filenames.

Example:

```txt
Schematic id: minecraft:castle/tower alpha
Fallback filename: minecraft-castle-tower-alpha.png
```

Do not commit copyrighted Minecraft texture assets here unless you have the right to use and distribute them.
